# LX04 PC Bridge

**中文** · [English](README.en.md)

把小爱音箱触屏版 **LX04** 变成 Windows 电脑的麦克风、扬声器和桌面状态副屏。电脑运行上位机，音箱运行 Android APK，可通过 USB、无线 ADB 或局域网配对连接。

## 功能介绍

### 双向音频桥接

- **音箱 → 电脑麦克风**：将音箱采集的声音送入 VB-CABLE，在微信、QQ、会议或语音输入软件中选择 `CABLE Output` 使用。
- **电脑 → 音箱扬声器**：通过 Hi-Fi Cable 采集电脑播放的声音，发送到音箱播放。
- 麦克风和扬声器可分别静音，支持音箱试音、输入电平查看和电脑主音量同步。
- USB / 无线 ADB 模式支持硬件麦克风直采和小爱让麦；是否可用取决于音箱 ROM 与权限。局域网直连模式使用 App 录音。

### 电脑状态副屏

音箱的 **800 × 480** 屏幕可以显示 CPU / GPU 使用率与可读取的温度、内存、磁盘、网速、开机时长和连接状态。温度等传感器数据受硬件、驱动及可选监测工具影响，读取不到的字段不会伪造数值。

- 多盘卡片最多显示 **4 个盘**，短按可切换磁盘 IO / 容量占用。
- 日期、时、分、秒可分别控制显示。
- 状态栏区分 USB ADB、WiFi ADB 和 WiFi 局域网连接。

### 自定义界面与样式同步

- 支持深色 / 浅色主题，卡片标题、大字指标、多条小字、字号与配色可调整。
- 在电脑端编辑，或在音箱端长按卡片编辑，样式双向同步；电脑端提供 HUD 预览。
- 最多上传 **3 张背景图片**，可调卡片和按钮不透明度。
- 支持整机系统旋转和仅翻转桥接 HUD 的吊装模式；系统旋转需授予 `WRITE_SETTINGS`。
- 上位机采用 PySide6 / QML 和 FluentWinUI3 样式，使用 Lucide 图标；页面宽度与滚动条随窗口布局调整。

### 屏幕镜像与系统通知

- 将选定的电脑显示器画面投到音箱，可选择镜像质量档位，并切回状态监视页。
- 将支持的 Windows 系统通知标题、正文和按钮同步到音箱；点击音箱上的按钮会尝试操作电脑上的对应通知。
- 开启后台运行后可隐藏桥接画面，保留音频服务，把屏幕交还给小爱原界面。

### 连接与稳定性改进

设备刷新、连接和诊断探测在后台执行，减少界面阻塞。连接具备心跳保活和自动重试，并修复了分段读取超时、取消连接后的迟到回调、旧连接影响新会话等问题。音箱端同时改进了连接切换、断开状态清理及配对码失效处理。

## 三种连接方式

### USB 数据线

音箱开启 USB 调试，用数据线连接电脑并允许调试授权。上位机选择 USB 连接方式，刷新设备后连接。ADB 通道可用于安装 APK、硬件麦克风直采、小爱让麦和系统控制。

### WiFi · 无线 ADB

先用 USB 连一次，在上位机读取音箱 IP 并激活无线 ADB，之后使用音箱 IP 连接。它沿用 ADB 通道，支持与 USB 相同的桥接功能；音箱重启后通常需要重新通过 USB 激活。

### WiFi · 局域网直连

电脑和音箱连接同一局域网。在音箱上打开 WiFi 配对模式，再在上位机扫描或填写 IP，输入音箱屏幕上的 **6 位配对码**并连接。成功后保存令牌，后续可免码重连。

- 不依赖 ADB；不提供硬件麦直采和小爱让麦，麦克风改用 App 采集。
- 配对码不随发现广播发送，配对结束后失效；多次错误会触发冷却。
- 使用受信任的局域网；配对鉴权不等同于加密传输。
- 音频 / 控制、镜像、通知分别使用 TCP **17890 / 17891 / 17892**，发现与配对使用 UDP **17893**。

## 使用前准备

- **电脑**：Windows 10 / 11，64 位。
- **音箱**：LX04，Android 8.1+；固件必须允许安装第三方 APK。原厂受限固件需要先具备这一条件，本项目不提供刷机工具。
- **麦克风通道**：安装官方 [VB-CABLE](https://vb-audio.com/Cable/)。
- **电脑声音回放到音箱**：另外安装同一官方页面提供的 Hi-Fi Cable。两者用途不同，安装后按提示重启电脑。
- **USB / 无线 ADB 初次设置**：需要可传数据的 Micro USB 线、可用的 ADB 驱动和 USB 调试授权。

上位机打包版内置 ADB，运行时不需要安装 Android SDK 或 Python。VB-Audio 虚拟声卡需自行安装；CPU 温度监测可选用 MSI Afterburner，项目不附带这些工具的安装包。

## 快速开始

1. 准备好上述环境，将音箱通过 USB 接入电脑。
2. 运行 `host\adb\adb.exe devices -l`，确认设备状态为 `device`；若显示 `unauthorized`，在音箱上允许调试授权。
3. 运行 `host\install_apk.bat`：覆盖安装当前 APK，授予录音和系统设置权限，并启动后台桥接服务。
4. 双击根目录的 `启动上位机.bat`，选择连接方式并连接音箱。
5. 在需要使用麦克风的软件里选择 `CABLE Output`；需要电脑声音回放时确认已安装 Hi-Fi Cable，再点“音箱试音”检查播放链路。

安装 APK 属于更新应用，无需重新刷写音箱系统。升级涉及音箱端功能时，应同时更新上位机与 APK。

## 构建与分发

源码运行上位机：

```powershell
python -m pip install -r host/requirements.txt
python host/pc_host.py
```

构建上位机和 APK（APK 构建需要 JDK 17+、Android SDK 与可用的 Gradle 环境）：

```powershell
python build_host_exe.py --no-commit
python build_apk.py --no-commit
```

- **上位机**：`dist/LX04-PC-Bridge-Host/LX04-PC-Bridge-Host.exe`。分发时必须复制整个 `LX04-PC-Bridge-Host` 文件夹，包含 `_internal`，不能只发 EXE。
- **音箱 APK**：`dist/LX04-PC-Bridge.apk`。
- 两个构建脚本默认会尝试创建本地 Git 快照；以上使用 `--no-commit` 仅生成产物。
- 维护者创建新版本时可运行 `python pack_release.py --bump -m "release notes"`，同时构建两端并创建本地版本提交。

## 常见问题

- **USB 设备不出现**：先检查 Windows 是否识别到音箱，再检查 ADB 驱动、调试开关和授权。只有历史设备记录不代表当前在线；MTP 本身也不能保证 ADB 可用。
- **无线 ADB 重启后连不上**：先接 USB，重新激活无线 ADB。
- **直连无法配对**：检查双方局域网是否互通、配对窗口是否开启、配对码是否有效，以及防火墙是否放行对应端口。
- **麦克风静音或无声**：检查录音权限、麦克风静音状态和小爱是否占用麦克风；不同 ROM 的硬件直采支持可能不同。
- **温度缺失**：并非所有硬件都提供可读传感器，无可用数据时会省略显示。
- **镜像或通知有兼容性问题**：这些功能受 Windows 环境影响，已知问题见更新记录，不保证所有应用的通知都能交互。
